# 定书尺
面向长篇网文作者的本地桌面设定维护工具，基于 Tauri 2 + Rust。

> 帮助作者管理人物、势力、宝物、地点，自动扫描书稿，检查设定冲突，跟踪伏笔埋入与回收，回溯角色剧情状态。

## 支持
本项目创作者入驻爱发电：
https://afdian.com/a/dingshuchi

软件本体免费下载，自带试用额度；购买永久授权码解锁全部功能。
所有原始文稿仅在本机解析，软件不会自动上传正文。

## 功能清单
- 批量导入 TXT 书稿
- 自动提取设定实体
- 跨章节一致性自查，降低吃书
- 长线伏笔台账、埋坑/回收记录
- 角色剧情时间线回溯
- 生成章末盘点、人物摘要素材

## 版本
- ✅ 安装版：支持自动差分更新、标准卸载
- ✅ 绿色便携版：解压即运行，可放移动硬盘，手动更新
